# 🎮 GalaxyHub Games Website

GalaxyHub is a browser-based gaming platform that brings multiple fun mini-games together in one place. The project is built using HTML, CSS, and JavaScript with a focus on responsive design and interactive gameplay.

## ✨ Features
- Multiple mini-games in one hub
- Responsive user interface
- Interactive gameplay mechanics
- Clean and user-friendly design
- Fast and lightweight

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)

## 🎯 Current Games
- Rock Paper Scissors
- TIC TAC TOE
- Snake Game
- meteor dodge
- More games can be added in future updates

## 🚀 Future Improvements
- Score tracking system
- Dark mode
- Additional mini-games
- Leaderboard integration
